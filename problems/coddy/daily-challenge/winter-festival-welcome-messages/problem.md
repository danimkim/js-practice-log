Write a function `createWelcomeMessage` that takes `festivalName`, `attractionName` and returns a welcome message with the attraction name reversed.

The function creates a welcome message by combining the festival name with the reversed attraction name.

Parameters:

- `festivalName` (string): The name of the winter festival
- `attractionName` (string): The name of the festival attraction

Returns: A welcome message string. Format:

```
Welcome to [festivalName]! Visit our [reversed attractionName]!
```
